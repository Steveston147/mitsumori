# PR16 共通プログラム基礎情報

係数方式と積み上げ方式で共通利用する基礎情報を画面上部に配置します。

## 項目

- プログラム名称
- 大学名・機関名
- 開始日
- 終了日
- 期間（開始日・終了日から自動計算）
- 学生人数
- 引率者人数
- 総人数（自動計算）
- 実施キャンパス・主な実施場所
- 宿舎名
- チェックイン日
- チェックアウト日
- 初回キャンセル料発生日
- 宿舎手配主体
- キャンセル条件メモ

## 動作

- 共通情報はブラウザの localStorage に保存します。
- プログラム名称、学生人数、期間は既存の係数方式・積み上げ方式の計算入力へ連動します。
- 既存画面の重複入力欄は非表示にします。
- 初回キャンセル料発生日は、将来ほかのアプリでアラート基準として利用できる独立した日付データです。
